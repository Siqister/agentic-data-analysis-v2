# Resources

Every API, file, or dataset this project is allowed to use.

* [U.S. Census Bureau Data API](census_api.md) - Census Bureau API serving American Community Survey (ACS) tables.
* [Cleveland Police crime incidents](cle_crime.md) - Offenses reported to the Cleveland Division of Police, one row per offense, with point locations.
* [Census tract relationship file, 2020 ↔ 2010 (Ohio)](census_tract_relationship_2020_2010.md) - Census Bureau table of every overlapping pair of a 2020 and a 2010 census tract in Ohio, with their shared land area.
