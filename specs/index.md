# Specs

The source of truth for this project: one Markdown file per item, following the Open Knowledge Format (OKF) v0.2. See [architecture.md § 3](../architecture.md#3-specs-and-the-open-knowledge-format).

* [Resources](resources/) - Every API, file, or dataset this project is allowed to use.
* [Geographies](geographies/) - Every boundary file we report on.
* [Crosswalks](crosswalks/) - Every conversion from one geography to another.
* [Indicators](indicators/) - Every measure we calculate.
* [Visualizations](visualizations/) - Every map we produce.
