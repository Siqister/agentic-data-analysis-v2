# About

Census block groups drawn for the 2020 census, from the Census Bureau's 2020 **cartographic boundary file** for Ohio (1:500,000). Cartographic boundaries are clipped to the shoreline, so block groups along Lake Erie don't extend over the water, as they do in TIGER/Line.

The file covers all of Ohio: 9,466 block groups, coordinate system EPSG:4269 (NAD83). It is fetched automatically from the URL above into a snapshot under `data/raw/`.

Fields used: `GEOID` (12 digits: state, county, tract, block group). The file's name fields (`NAME`, `NAMELSAD`) hold only the block group number, e.g. `Block Group 2`, so there is no `name_field`.

# Which units are included

**Majority-area rule:** a block group is in `bg_2020` if more than 50% of its area is inside `cle_city`. Areas are measured in EPSG:3734.

The rule keeps the city's block groups whole: each one is either in or out. Block groups that straddle the city line are counted fully in or fully out, so city totals built from them differ a little from totals for the exact boundary.

# Notes

- Block groups with zero population (e.g. industrial land, the airport) are kept. Their values are handled by the Indicator.
- Area is measured from the clipped cartographic shapes, so water doesn't count toward a block group's area.
